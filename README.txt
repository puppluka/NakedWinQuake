
This is a random hack-together of "Iqhor", a game engine I'm putting together as a side project to suit my needs and interests.
Think of it as id Tech 2.25, if id Tech 2.5 is Quake 2.

Added cutscenes, a few extra console commands, and general code changes to suit my needs and perhaps affect stability.
Expect constant software rendered goodness! <3

Any build made from the repo should just work, unless there's a commit note otherwise.
Utilizes SDL3 + integrated ogg + screenshot libraries.

Thanks to the authors of the NakedWinQuake lineage of forks and code for making this possible!
